# Bike Rental Demand Prediction

## Project Overview

This project predicts bike rental demand using historical rental data and environmental conditions.

## Business Problem

Bike rental companies need accurate demand forecasting to optimize inventory and improve customer satisfaction.

## Features

- Season
- Temperature
- Humidity
- Windspeed
- Holiday
- Working Day
- Weather Situation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Building
6. Model Evaluation
7. Demand Prediction

## Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score
